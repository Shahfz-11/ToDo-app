# ToDo App

A simple and clean ToDo list application that helps you manage your daily tasks. Add new tasks, mark them as completed, and delete them when you're done.

## Features

- Add new tasks
- Delete tasks
- Clean and responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Shahfz-11/ToDo-app.git
   ```
2. Open the project folder:
   ```bash
   cd ToDo-app
   ```
3. Open `index.html` in your browser.
